## docsify 图片相册网格（the-jelly-note）

需求：文章图片排成相册样式，点击才放大。

- 放大能力原本就有：`index.html` 已启用官方 zoom-image 插件（medium-zoom，`zoomImage: true`）。
- 本次新增自写零依赖插件（`index.html` plugins 数组末尾）：
  - `doneEach` 后扫描 `.markdown-section`，把「连续、纯图片」的 `<p>` 合并包进 `.photo-gallery` 网格容器；
  - 判定纯图片段落：p 内有 img 且去掉 img/a 后无文本——文字+配图段落不受影响（游记里的 emoji 小图标正常保留）。
- 新增 CSS：`.photo-grid` grid 布局（auto-fill, minmax(170px,1fr)），缩略图 170px 高 object-fit:cover、圆角阴影、hover 上浮；≤600px 窄屏降为 110px 高两列。
- 已用 python http.server:8644 + agent-browser 实测：
  - 游记页生成 5 组相册、44 张图进网格；文字配图/emoji 未被误伤；
  - 点击相册图片 medium-zoom 正常弹出（overlay=true zoomImg=true），显示完整原图不受 cover 裁切影响；
  - 手机端 390px 视口两列网格正常。
- 域名顺序坑：plugins 数组最后一个插件的 `}` 后无逗号，Edit 时 old_string 按此匹配。

## 替换 zoom-image 为自写 lightbox（同日下午）

需求：放大时图片被限制宽度；要求高度固定适应屏幕最大高度、宽度自动，横竖屏不同尺寸都最优呈现。

- 移除官方 `zoom-image`（medium-zoom）：删 `index.html` config 的 `zoomImage:true` 与 `<script zoom-image.min.js>`，避免两套放大机制打架。
- 新增自写 lightbox 插件（`plugins` 数组末尾）：点击正文任意 `.markdown-section img` → 全屏遮罩；document 级事件委托，图片被相册插件移动后仍可命中；支持 ← → 切换、ESC / 点遮罩关闭、顶部 `x / N` 计数。
- 核心 CSS（`.lightbox-img`）：`max-width:95vw; max-height:92vh; width:auto; height:auto; object-fit:contain`——浏览器自动 contain 缩放，高度优先撑满（竖图）、宽度优先撑满（横图），互不裁切/拉伸。
- 实测（http.server:8645 + agent-browser）：
  - 竖图 1280×1707 → 显示 393×523（height≈92vh 撑满，ratio 0.750 无拉伸）；
  - 横图 1702×1276 → 显示 698×523（受 92vh 限取最优，ratio 1.334 无拉伸）；
  - ArrowRight 切换 1/53→2/53；点遮罩关闭 display=none。
- 注意：emoji/小图标若是 `<img>` 也会被点亮放大（docsify 默认不把 emoji 转 img，本站未见问题）。
