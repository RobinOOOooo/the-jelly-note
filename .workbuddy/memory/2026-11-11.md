# 2026-11-11

## 灯箱图片查看器（自写 lightbox，无外部依赖，仅改 index.html）

需求演进：
1. 初版：点击放大 + contain 适配（高度优先撑满，横竖屏各取最大可见尺寸，不裁切不拉伸）；← → 切换、ESC/点遮罩关闭。
2. 加旋转按钮（顶部右侧 × 左边，SVG 旋转图标，hover 图标自身转 90°）。
3. 旋转需求变更（用户纠正）：**不是持续自转**，而是「点一下旋转按钮转 90°，停在当前角度」，再点再转 90°。
   - 实现：旋转按钮调用 `rotate()`：`rotation = (rotation + 90) % 360; applyGeom();`，无 spinning/rAF/loop。
   - contain 适配统一为：`rotation%180===0` 用 `min(vw/iw, vh/ih)`；否则（90/270）用 `min(vw/ih, vh/iw)`，竖图转横后高度撑满、宽度自动，不出界。
   - 切图（← →）时 `rotation` 重置为 0；关闭灯箱不再需要停自转（已无 rAF）。
   - 注意：之前用 Edit 工具因全角/缩进字符匹配失败，最终用 Python 正则整块替换才生效（index.html 改动优先用正则或 Python 而非 Edit 逐段）。

实测（agent-browser）：连续点击旋转按钮，inline transform 依次为 rotate(180)→270→0→90→180，每步 +90 顺时针步进，停在当前角度。
