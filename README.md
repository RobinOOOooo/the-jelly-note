# 🫧 果冻记

> 记技术，记生活，也记那些没来由的念头。<br>不为什么，只是怕日子流过去，连个回声都没有。

欢迎来到果冻记。

这里是我的一方小天地——路上遇见的、家里发生的、半夜里忽然想通的，都先存着。技术、生活、思考，想到什么就记什么。不急着写，也不急着给答案，留着慢慢翻。

## 这里有什么

- **[🤔 思考随笔](posts/notes/README.md)** —— 对一些事的看法，半夜里想通的道理，读完书的那点回甘。

## 关于

我是果冻，住在西安。一有空就爱开车带全家往外跑，后座常坐着两个吵闹的小家伙。

果冻记就是个随手记的地方——走过的路、家里的热闹、脑子里冒出来的想法，都留在这里。写得不快，但一直在写；哪天断了，多半是日子太忙，或者太好。

技术、生活、思考，想到什么就记什么。
