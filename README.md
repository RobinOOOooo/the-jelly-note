# 果冻记

> 把鸡零狗碎写成诗 —— 日记、随笔、突然冒出来的念头，想到就记，记完再说。

欢迎来到果冻记。这里是果冻的一块自留地——日子是流水，记下来就成了诗；话是零碎的，攒起来就是生活。路上的风、家里的吵闹、半夜突然冒出来的想法，都往这儿丢，攒着以后翻。

## 这里有什么

- **[🧭 旅行游记](posts/travel/README.md)** —— 一有假期就开车带全家往外跑。路线、吃住、踩过的坑，配图配视频，长篇流水账；一年几趟，趟趟不一样。
- **[📝 日常点滴](posts/daily/README.md)** —— 每天一篇日记：今天干了什么、想到了什么、被什么逗笑了，长短不拘，三言两语也算一篇。
- **往后想到什么，再开什么栏目** —— 比如"突然想到的"，比如"看完什么之后"。不定期上新，空着的地方都算预告。

## 关于

我是果冻，住在西安，平时上班，一有假期就喜欢开车带全家出去跑，后座常年有两个娃制造噪音。果冻记就是个随手记录的地方——路上看到的、家里发生的、脑子里冒出来的想法，都记下来留着以后翻。

写得不算快，但一直在写；哪天断更了，多半是日子太忙，或者日子太好，顾不上记。
